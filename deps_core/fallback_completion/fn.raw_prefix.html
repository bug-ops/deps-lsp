pub fn raw_prefix(line: &str, character: u32) -> &str
Expand description

Extracts what the user has typed on line up to the cursor (character, a UTF-16 code unit count), trimmed of whitespace.

character is converted via crate::completion::utf16_to_byte_offset; when the cursor sits beyond the line’s UTF-16 length (None), this clamps to the full line rather than panicking on an out-of-bounds slice.
