Function snapshot_guard_async

pub async fn snapshot_guard_async() -> MutexGuard<'static, ()>
Expand description

Async counterpart of snapshot_guard, for a test whose measured section spans an .await point (e.g. an async load_document_from_disk call).

A std::sync::MutexGuard held across an .await would stall the runtime for the duration of the wait — this returns a tokio::sync::MutexGuard instead, which is safe to hold across .await.

§Panics

Never panics — unlike snapshot_guard, this is always safe to call from an async execution context, since it yields to the runtime instead of blocking the thread.

§Examples

use deps_core::fs_probe::{snapshot, snapshot_guard_async};

let _guard = snapshot_guard_async().await;
let (stats_before, _) = snapshot();
// ... perform the async operation under test ...
let (stats_after, _) = snapshot();
assert!(stats_after >= stats_before);
