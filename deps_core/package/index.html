Module package

Expand description

Newtypes distinguishing package names, version requirement strings, and concrete resolved versions.

PackageName, VersionReq, and ConcreteVersion wrap String to give these kinds of manifest and registry data their own types, so a function that expects one cannot accidentally be called with another. None of these types validate, trim, or normalize their contents: ecosystem-specific normalization (case folding, separator rewriting, etc.) belongs to EcosystemFormatter, not to these types. See each type’s documentation for details.
