Deno/JSR ecosystem support for deps-lsp.

Parses deno.json/deno.jsonc manifests and routes each imports entry to the right registry: jsr: specifiers to a JSR registry client (this crate), npm: specifiers to the existing deps-npm client — through a single dispatching deps_core::Registry facade, DenoRegistry. See crate::registry’s module docs for the full architecture.
