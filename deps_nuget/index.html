NuGet/.NET project file parsing and registry integration.

This crate provides NuGet ecosystem support for the deps-lsp server, including .csproj/.fsproj/.vbproj, Directory.Packages.props, and packages.config parsing, packages.lock.json lock file support, and NuGet V3 registry integration.
