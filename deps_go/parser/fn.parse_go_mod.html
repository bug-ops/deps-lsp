Parses a go.mod file and extracts all dependencies with positions, using a fresh, default GoParseContext.

No live $GOENV policy handle — every dependency resolves to plain deps_core::parser::DependencySource::Registry, byte-identical to pre-#519 behavior. Production parsing goes through parse_go_mod_with_context instead.
