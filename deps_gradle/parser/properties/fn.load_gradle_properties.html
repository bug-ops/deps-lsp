pub fn load_gradle_properties(start_dir: &Path) -> HashMap<String, String>
Expand description

Finds and parses gradle.properties files by walking up from start_dir.

Merges properties from all levels, with child values overriding parent values. The walk stops after MAX_CONFIG_ANCESTOR_DEPTH ancestors regardless of whether the filesystem root has been reached, and each file is read through deps_core::fs_probe::read_to_string_capped — bounded by deps_core::MAX_CACHED_FILE_BYTES, the same cap deps-cargo’s/deps-npm’s own config-file ancestor walks use (a gradle.properties file is a small config file, not a lock file, so it does not need deps_core::lockfile::MAX_LOCKFILE_BYTES’s larger cap) — so an oversized or maliciously deep ancestor chain cannot force unbounded work (CWE-400).
