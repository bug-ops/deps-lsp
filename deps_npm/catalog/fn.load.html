Expand description

The fallible half of catalog resolution: locates and parses the nearest-ancestor pnpm-workspace.yaml, if any.

None means there is nothing to resolve against — no manifest_dir at all (e.g. a non-file: manifest URI), or no ancestor pnpm-workspace.yaml found. A workspace file that was found but is unreadable (vanished between discovery and read, or is not a regular file) instead comes back as a defective PnpmWorkspaceConfig carrying ConfigDefect::Malformed, not None — apply treats both None and a defective config as an unresolved outcome, but keeping them distinct here matches deps_core::MtimeFileCache::get_or_parse’s own contract.

§Examples

use deps_npm::catalog::{PnpmWorkspaceCache, load};
use std::path::Path;

let cache = PnpmWorkspaceCache::new();
assert!(load(Some(Path::new("/nonexistent/workspace")), &cache).is_none());
assert!(load(None, &cache).is_none());
